# gn-downloader
Want to download the entire GN Math Library but don't want the absolute pain of clicking the download button 30 million times?
Well, you don't have to. With gn-downloader, grabbing the entire library becomes a breeze with only a single button click.
Sure, you might have to wait about 3 minutes for it to finish—but you're not that impatient, right?

Disclaimer: I do not own any of these games, nor am I collaborated with the GN Math developers.
I just wanted to build an easier tool so nobody has to rely on janky workarounds.
